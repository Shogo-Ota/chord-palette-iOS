# ピアノ・エレピ音源 品質調査と改善案（v1.01）

- 作成日: 2026-08-03
- 範囲: 調査と改善案。大規模な音源差し替えは承認後。

## 現状アーキテクチャ

| 層 | 役割 |
|---|---|
| JS PerformanceEngine | `NoteEvent[]`（楽器非依存） |
| `audioService` | ネイティブへの唯一の窓口 |
| `SampledInstrumentProvider` / SoundFont | ピアノ・エレピ等のサンプル発音 |
| ミキサー | chord / drum / master 音量 |

音色 ID はユーザー選択（スタイルは強制しない）。City/Ballad カードは octave / groove で「聞こえ」を変える。

## 調査で見える課題

1. **サンプルの機械感** — Round Robin はあるが、ベロシティ層が粗いとアタックが単調。
2. **エレピ** — Rhodes 専用の高品位セットは未バンドル。GM/既存サンプル依存で Band/R&B の「エレピ感」は弱い。
3. **低域濁り** — warmLow ボイシング＋長い sustain で iPhone スピーカーが飽和しやすい。
4. **リリース** — `releaseCut` で短めにできるが、デフォルト「自然」は Ballad 向き・Band では残響過多になり得る。
5. **ダイナミクス** — エンジン側の velocity 幅が狭いと音源の層を使い切れない。
