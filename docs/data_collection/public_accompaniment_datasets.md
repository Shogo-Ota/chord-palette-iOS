# ピアノ／エレピ／ベース向け 公開人間演奏データセット調査

- 作成日: 2026-08-03
- 方針: ユーザー自作 MIDI を初期前提にしない。公式配布・ライセンス明確な公開データを優先する。
- 関連: `docs/data_collection/gmd_acquisition.md`（ドラム = GMD 確定）、`docs/midi_dataset_policy.md`

## 判定ルール（本調査）

| 判定 | 意味 |
|---|---|
| **採用候補** | ライセンスが CC BY / CC0 等で商用・派生が明確、かつ人間演奏（またはそれに近い）MIDI |
| **見送り** | NC（非商用）・学術限定・著作権混入リスク・ライセンス不明 |
| **代替検討** | 適切な公開データが無いパート向け。自作／演奏依頼は **最後の手段** |

アプリ・リポジトリへの **元 MIDI 同梱は全候補で不可**（社内ポリシー）。統計プロファイルのみコミット対象。

## 結論（確定・v1.01）

| パート | 判定 | 備考 |
|---|---|---|
| ドラム | **採用候補 = GMD**（将来タスク） | 取得済み・Profile あり。**v1.01 ではエンジン反映・追加解析を保留**（`gmd_acquisition.md`） |
| ピアノ | **候補 = ATEPP**（取得・解析は後段） | CC BY。古典ソロ → 伴奏語彙への転用は限定的。本フェーズでは表の確定のみ |
| エレピ | **該当なし（見送り）** | 商用可の専用人間演奏セット未発見 |
| ベース | **該当なし（見送り）** | FiloBass は NC。NeuralAcid は合成のため MEASURED Humanize 不適 |

**v1.01 方針（添付計画）**: 公開データの比較表を確定し、**取得・解析パイプライン投入は行わない**。伴奏改善は Reference Songs の言語化（HYPOTHESIS）＋ Baseline 評価＋ Design Target 調整で進める。

### 代替案（公開データが無いパートのみ・現時点では実行しない）

1. プロ奏者への短尺オリジナル伴奏の演奏依頼（特定市販曲のコピー採譜は禁止）
2. オーナーによるオリジナル打ち込み／演奏（初期前提にはしない）
3. 商用 MIDI ライブラリの正式購入（Toontrack 等。ライセンス条項を台帳に記録）

**ユーザーへの MIDI 収録依頼は、公開データ経路を尽きた後に再提案する。**
