## 全ジャンル共通で見る項目（最低限 7 点）

各曲ですべてを細かく分析する必要はない。最低限、次を見る。

1. **コード楽器** — ブロック／アルペジオ／刻み／シンコペーション。音域、転回形、音数、音価
2. **ベース** — ルート中心か動くか。キックとの関係。次コードへのアプローチ
3. **ドラム** — キック／スネア／ハイハットの基本配置。8ビート／16ビート／ハーフタイム／4つ打ち。フィルの位置
4. **タイミング感** — 前ノリ／ジャスト／後ノリ。パート全体が一緒にずれるか、特定パートだけか
5. **強弱と音数** — Aメロ／Bメロ／サビで何が変わるか。ベロシティ、音域、密度
6. **フレーズ単位の変化** — 1〜4小節が完全反復か。4／8小節目の変化。コード切替前の余白や導入音
7. **Chord Palette へ抽象化できる点** — 他進行でも再利用可能か。楽曲固有のリフ／メロディではないか

## Ballad

### 最重要ポイント

#### 1. ピアノの音価と余白

どの音を弾くか以上に、どのくらい伸ばすか／どこで切るか／次のコード前に余白を作るかが重要。

確認すること:

- 1コードを長く保持するか
- コード切替直前まで伸ばすか
- 右手だけ先に離すか
- フレーズ終端で音数を減らすか

#### 2. ボイシング移動

- 各コードで最低限の移動になっているか
- トップノートが旋律的に動くか
- 内声に共通音を残しているか
- 左手が低すぎて濁っていないか

#### 3. 密度の変化

- Aメロは単音・薄いコードか
- サビでオクターブ、トップノート、音数が増えるか
- 同じパターンを強く弾くだけか、演奏内容自体も変わるか

#### 4. ペダル

- コードごとに踏み替えるか
- 完全に切らずに残響をつなぐか
- 低音だけ濁らないよう短くしているか

### Chord Palette に抽出したい要素

- 長い音価
- 滑らかな転回形
- フレーズ終端の余白
- 4小節単位の密度変化
- サビでの音域・ベロシティ上昇

### コピーしないもの

- 特徴的なイントロ
- 歌メロと一体化したピアノフレーズ
- 曲固有のトップノート進行

## Band

### 最重要ポイント

#### 1. ドラム・ベース・コード楽器の噛み合わせ

個々のパートより全体の推進力を見る。

- キックとベースが同時に鳴る位置
- スネアの2拍・4拍との関係
- コード楽器がキックに合わせて鳴るか
- ハイハットやギターの刻みが全体を前へ進めているか

#### 2. 8ビートと16ビートの違い

- 8分刻み中心か
- 16分のゴースト的な刻みが入るか
- すべての8分を均等に弾くか
- アクセント位置が一定か

#### 3. コードのアタック

- 音を伸ばすより短く切るか
- 各拍でコードを鳴らすか
- 裏拍だけ鳴らすか
- サビでストローク密度が増えるか

#### 4. ベースライン

- ルート8分中心か
- オクターブを使うか
- コード切替前に経過音を入れるか
- ドラムより前に出るか、後ろで支えるか

#### 5. セクション変化

- Aメロではハイハット閉じ気味か
- サビでクラッシュやオープンハイハットが増えるか
- 4小節終端にフィルが入るか
- ブレイクや全パート停止があるか

### Chord Palette に抽出したい要素

- キックとベースの同期
- 8分刻みのアクセント規則
- 短めのコード音価
- 4・8小節終端のフィル
- サビでの密度増加

### コピーしないもの

- ギター固有のリフ
- 原曲のドラムフィルそのもの
- 歌メロに反応する固有フレーズ

## City

### 最重要ポイント

#### 1. 16分音符の配置

単に16分が多いのではなく、鳴らさない16分位置が重要。

- 表拍ではなく裏や16分後半にコードが入るか
- 同じシンコペーションを反復するか
- ハイハットとコード楽器が同じ位置にあるか
- 小節ごとにアクセント位置が変わるか

#### 2. コードの色

- Maj7、m7、9th、13thなどをどの音域に置くか
- テンションをトップに置くか内声に置くか
- 低音域に音を詰めすぎていないか
- ボイシングが平行移動か、滑らかに接続するか

#### 3. コード楽器の演奏方法

- エレピの短いコンピング
- 右手コード＋左手単音
- 裏拍で短く切る
- アルペジオよりリズミックなコードヒット中心か

#### 4. ベースの動き

- ルート以外のコードトーンを使うか
- クロマチックなアプローチがあるか
- 16分の細かい動きがあるか
- キックと完全一致せず、補完関係になっているか

#### 5. ドラムの細部

- ゴーストノート
- ハイハットの強弱
- オープンハイハットの位置
- スネアがジャストか少し後ろか
- キックが均等ではなくシンコペートするか

### Chord Palette に抽出したい要素

- 16分シンコペーション
- テンションを含む省略ボイシング
- 短いエレピ音価
- ベースのアプローチノート
- ドラムとコードの補完配置

### コピーしないもの

- 原曲固有のカッティング
- 特徴的なベースリフ
- 固有のテンション進行

## Dance

### 最重要ポイント

#### 1. キックと低域

最初に見る:

- キックが4つ打ちか
- シンコペートするか
- ベースがキックと同時か、隙間に入るか
- 低域が長く重ならないか

#### 2. 反復の設計

反復は多いが完全に同じではない。

- 1小節パターンを何回繰り返すか
- 4小節目で何が変わるか
- 8小節目でフィルやブレイクがあるか
- ハイハットやパーカッションだけが増減するか

#### 3. コードの役割

- 長いパッドか
- 短いスタブか
- 裏拍コードか
- アルペジエーター的な反復か
- コード音域が中高域に寄っているか

#### 4. ビルドとドロップ

- 音数が徐々に増えるか
- フィルター的な変化があるか
- ドロップ直前に無音や短い停止があるか
- ドロップ後に低域が追加されるか

#### 5. Humanize の量

人間らしいランダムさを増やしすぎないことも重要。

- キックはかなり正確か
- ハイハットだけ小さく揺れるか
- ベロシティ変化は規則的か
- 生演奏感より反復の安定感を優先しているか

### Chord Palette に抽出したい要素

- 4つ打ち／シンコペートキック
- キックとベースの棲み分け
- 1・4・8小節単位の変化
- 短いコードスタブ
- 控えめな Humanize

### コピーしないもの

- 特徴的なシンセリフ
- 原曲のドロップ構成そのもの
- ボーカルチョップや固有サンプル

## R&B

### 最重要ポイント

#### 1. 後ノリの正体

「R&Bは後ノリ」と一括りにせず、どのパートが後ろなのかを見る。

- スネアだけが少し遅いか
- コード楽器も後ろか
- ベースはキックに近いか
- ハイハットはジャストで、スネアだけ遅いか
- 小節全体が遅れているのではないか

#### 2. 余白

- コードを毎拍鳴らしていないか
- キックのない場所をベースが埋めるか
- コードとベースが交互に入るか
- 無音部分がグルーヴを作っているか

#### 3. コードボイシング

- 7th、9th、11th、13thの使い方
- ルートをコード楽器から省略するか
- トップノートが滑らかに動くか
- 中音域へ音を集めているか
- コード内の音を同時ではなく少しずらして鳴らすか

#### 4. ベース

- 音価が短いか長いか
- ルートを外すタイミング
- ゴーストノートやアプローチ
- キックの直後または直前に入るか
- フレーズ終端で次コードへ導くか

#### 5. ドラム

- ハーフタイム感があるか
- スネアまたはクラップの位置
- ゴーストスネア
- ハイハットの3連・細かいロール
- キックが疎でシンコペートしているか

### Chord Palette に抽出したい要素

- パート別の後ノリ
- 疎なコード配置
- ルート省略テンションボイシング
- キックとベースの会話
- ゴーストノート
- 短いフレーズと余白

### コピーしないもの

- 特徴的なボーカル周辺フレーズ
- 曲固有のベースリフ
- 特定のドラムロール

## 運用ルール

1. 曲目表の「教材として見るべき伴奏要素」が空でも正常（分析 0 件）
2. 聴取メモを書くときは必ず [`song_analysis_template.md`](./song_analysis_template.md) を使い、冒頭に `HYPOTHESIS`（耳コピ／聴取メモ）か `MEASURED`（合法 MIDI／許諾音源の計測）を明記する
3. 曲名だけでは記入しない。未聴取は空欄のまま
4. 「抽出したい要素」だけをエンジン Design Target 候補にし、「入れてはいけない固有要素」は絶対にパターン化しない
