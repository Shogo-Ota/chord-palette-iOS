# Sprint 1 — ローカル作曲MVP（Phase 1）契約

正典: `Chord_Palette_iOS_MVP_Requirements_v1.md`（要件定義書）＋ 本契約。
本スプリントは **ローカル作曲のMVP** を対象とする。実音再生・動画書き出し・課金実装・SNS/認証は対象外（後続フェーズ）。

## スコープ（実装対象）

1. **プロジェクト永続化（expo-sqlite）**
   - 作成・取得・保存・複製・削除
   - 保存内容: タイトル / キー / BPM / 拍子(4/4) / 音色 / ドラム / 伴奏パターン / コードイベント配列
   - 初回起動時に「J-POP王道進行」を1件シード（以降シードしない）
2. **プロジェクト一覧（`src/app/index.tsx`）**
   - 実データ連動（更新日時降順）
   - 新規作成導線 / プリセット導線
   - カード長押しで複製・削除
   - 0件時の空状態表示
3. **エディター（`src/app/editor.tsx`）**
   - コード: 追加 / 削除 / 複製 / 左右移動 / 長さ変更（1/4・1/2・1小節）
   - 合計 **最大16小節** を超える追加を拒否
   - キー選択（12メジャーキー）で進行が自動転調表示
   - Undo
   - 保存（未保存/保存済み表示）、再読込で復元
   - 音色 / ドラム / 伴奏パターンの選択を保持し表示に反映
   - コード名を大きく、度数を小さく併記
4. **コードライブラリ / Proゲート（要件§7）**
   - 無料: ダイアトニック三和音・7th・sus4・add9
   - Pro（`palette_pro`）: 6th・借用和音（モーダルインターチェンジ）・セカンダリードミナント・オンコード（スラッシュ）・sus2・9・11・13・Pro音色（アコギ/エレキ/ストリングス）・Proプリセット
   - Proロック要素のタップで paywall へ誘導（未購入時）
5. **プリセット（度数保持・自動転調）**
   - 6プリセットを度数（tonicからの半音オフセット）で保持
   - 選択キーへ自動転調して読み込み
   - 無料=J-POP王道のみ、他はProゲート
6. **Entitlement抽象化**: `services/billing` モック（`palettePro=false`）＋純粋な `isLocked`

## 受け入れ基準（機能）

- [ ] 新規作成→コード追加→保存→アプリ再起動後も一覧・内容が復元される
- [ ] 一覧の件数・更新ラベル・コードプレビューが実データを反映
- [ ] 長押しで複製・削除ができ、一覧が即時更新される
- [ ] キーを変更するとタイムライン／ライブラリ／プリセットが正しく転調（例: 王道 in C=C·G·Am·F、in G=G·D·Em·C）
- [ ] 16小節ちょうどまで追加でき、超過する追加は無視される
- [ ] Proコード（セカンダリードミナント/借用/オンコード/6th/sus2/9/11/13）タップで paywall
- [ ] sus4・add9・ダイアトニック三和音/7th は無料で追加できる
- [ ] Pro音色（アコギ/エレキ/ストリングス）タップで paywall、Piano/E.Piano は選択可
- [ ] Proプリセットタップで paywall、J-POP王道は読み込める
- [ ] 度数併記（大きいコード名＋小さい度数）が表示される

## デザイン4基準（閾値: 各4/5以上）

- デザインの質: ダークテーマ（ネイビー/チャコール）、紫→青アクセント、虹色は過剰でない
- オリジナリティ: モック（Claude Design）とブランドに忠実
- クラフト: 角丸カード、十分なタップ領域、余白、高コントラスト、日本語UI、DAW的密集を避ける
- 機能性: iPhone縦向きで破綻なく操作でき、上記機能が動作

## エッジケース

- 空の進行での保存・再生画面表示
- 16小節上限での追加・複製の拒否
- 選択要素の削除後のselectedインデックス整合
- キー変更後のライブラリ/プリセット転調のスペリング（#/♭）
- プロジェクト0件時の一覧表示

## 対象外（このスプリントでは評価しない）

- 実音再生（Phase 2 / 現状は無音。再生ボタン・音量スライダーはビジュアルのみ）
- 動画書き出し（Phase 3）
- RevenueCat実課金・購入復元（Phase 4 / paywallは表示のみ、`palettePro=false`固定）
- SNS・認証・Convex（Phase 5+）

## 次スプリントへの申し送り（Sprint 1 完了時点）

- **11th/13th のディグリー別可否**: 11/13 は Pro バリエーションとして継続（ユーザー裁定）。ただし現状は全ディグリーに一律提示している。今後、音楽理論の正典に従い、ディグリーごとに理論的に成立する/しないを判定し、成立しないものはグレーアウト（または非表示）に出し分ける。要件定義書 §4.2 の「11th/13th は MVP対象外」記述は本裁定に合わせて追記修正する。
- **legacy データのマイグレーション**: 度数情報（`rootOffset`/`suffix`）を持たない旧 `ChordEvent`（Sprint 1 修正前に保存されたもの）は転調されない。必要ならロード時に `displayName` から `offsetFromTonic` で一度きり復元するマイグレーションを検討。

## 検証メモ（環境制約）

- 開発PCは Windows のみ。**EAS Build は Apple Developer 未登録のため実行しない**。
- Expo Go（SDK 54）＋実機で手動確認する前提。オフライン検証は `npm test` / `tsc --noEmit` / `expo lint` / `expo export` で代替済み。
