# Web版 Chord Palette から抽出した「美学」メモ（iOS版ブラッシュアップ用）

作成日: 2026-07-13
出典: https://chord-palette.vercel.app/ ／ `C:\AI Works\Chord Palette（web）`（v3.0.2 / 16スプリント）

> 本メモは iOS 版を今後磨く際の「見た目・体験の指針」。**すぐに実装する必要はない**。対話でUIを詰めるときの参照。

---

## 1. 世界観（一言）
「暗い作曲アプリらしい静けさ」の上に、**コード機能（T/SD/D）を色で語る**理論可視化。装飾は控えめ・機能は色で主張。

## 2. カラー言語（最重要・そのまま流用推奨）
- 背景: `--bg-primary #0a0a1a` / `--bg-secondary #111128`。全面に極薄の**放射状グラデ**（青6% / 赤4% / 琥珀4%）を敷いて奥行き。
- ガラス面: `rgba(255,255,255,0.04–0.06)` + `backdrop-filter: blur(16–24px)` + 1px の淡いボーダー。
- テキスト: primary `#f0f0f8` / secondary `#8888aa` / muted `#555570`。
- **機能色（アプリの背骨）**:
  - Tonic = 青 `#3b82f6`
  - Subdominant = 琥珀 `#f59e0b`
  - Dominant = 赤 `#ef4444`
  - 各色に bg(8%) / border(25%) / glow(30%) の3段を用意し、状態で使い分け。
- ブランド/課金アクセント: 青→インディゴ→紫（`#3b82f6→#6366f1→#8b5cf6`）。**課金CTAだけは紫グラデ**で機能色と別レイヤー化。
- Pro有効=緑 `#10b981`系（機能色と被らせない）。

## 3. 形・質感
- 角丸: `--radius 16px` / `--radius-sm 10px` / pill `50px`。
- カード上端 3px のアクセントライン（機能色）で種別を一目で示す。
- 影は「黒い drop-shadow」より **機能色の glow**（`0 0 12px var(--*-glow)`）を多用＝発光する暗さ。
- ボタン押下は `scale(0.95–0.97)` の微小フィードバック、hoverは `translateY(-2〜4px)`。
- 「編集中」= Tonic青の点滅グロー、「再生中」= 白枠+白グロー+微拡大。役割を色と動きで分離。

## 4. タイポ / 情報密度
- Inter / system-ui。数字は `font-feature-settings:"tnum"` で等幅。
- ラベルは極小(8–10px)・太字(800)・大文字・字間広め＝「小見出し」を静かに置く。
- コード名は大きく主役、度数(I/IVmaj7…)は小さく併記（iOS要件§5.3と一致）。

## 5. レイアウト / モバイル作法（iOSでも踏襲すべき）
- **375px 最優先**、320pxまで1行維持の徹底したブレークポイント設計。
- `env(safe-area-inset-*)` を padding に必ず取り込む（ノッチ/ホームインジケータ）。
- 下部は**ボトムシート**でコード選択（折りたたみ88px→展開）。上に成果物（進行ピル列）を常時見せる。
- 再生バーは意味グループで段組み（時間軸→音色軸→トランスポート）。視線移動を最小化。
- タップ領域は最低 40–44px を死守。

## 6. モーション
- 実用的な微モーション中心（0.12–0.28s ease）。過剰演出はしない。
- 録画/書き出し中は ⏺ の赤パルス、ロード中は subtle pulse で「状態」を伝える。
- 空状態は跳ねる矢印で次アクションを誘導。

## 7. 投稿動画の見せ方
- 暗背景・コード名を主役に大きく・進行ストリップ＋切替アニメ・情報過多にしない。
- フッターに `chord-palette.vercel.app`（指名検索/SEO導線）。iOS版もブランド表示は控えめに。

## 8. プロダクト哲学（体験の芯）
- **試聴・基本スケッチは絶対に有料の内側に置かない**（無料で作品が完成する）。
- Proは「制限解除」でなく「響き・表現の拡張」。ロックは彩度を落としつつ金🔒で«気づかせる»中庸。
- 起動即作曲・強制登録/チュートリアルなし。

## 9. iOS版に持ち込む際の差分メモ
- Web の CSS 変数 → `src/theme/tokens.ts` に対応させ、機能色 T/SD/D と glow を一次トークン化する。
- ガラス/blur は RN では `expo-blur` 等で表現（多用しすぎると実機負荷、要バランス）。
- ボトムシート型コード選択は iOS でも自然。編集中/再生中の色・グロー表現を移植すると一貫性が出る。
- 動画書き出しの見た目（コード名主役・機能色ハイライト）は Web の構成をそのまま指針にできる。
