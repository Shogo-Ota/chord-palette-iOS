---

## 2. alt の定義（Chord Palette）

`7alt` は次のピッチクラスを含むものとする（ルート=0）:

- 3（M3=4）, b7（10）
- b9（1）, #9（3）, #11（6）, b13（8）
- 完全5度（7）は **省略可**（推奨ボイシングでは省略）

表示: `G7alt` / buttonLabel `alt`。

---

## 3. マイナー度数のオルタード

V 以外にも、キー内だがコードトーンの半音上に来るために classic theory がオルタード扱いする音がある。UI では V のオルタードと同じ段に置く。

| 度数 | buttonLabel | symbol | intervals | 構成音（C キー） |
|---|---|---|---|---|
| iii | ♭9 | m7(♭9) | `[0,3,7,10,13]` | E G B D F |
| vi | ♭13 | m7(♭13) | `[0,3,7,10,20]` | A C E G F |
| vii° | ♭9 | m7♭5(♭9) | `[0,3,6,10,13]` | B D F A C |

---

## 4. 方針

- オルタードは UI の第 3 段（`ALTERED_VARIATIONS`）に隔離する。core / extended の 2 段は「全音がキー内・アボイドを踏まない」を保つため、ここに挙げた音は出さない。段の定義は `Extensions.md` §0
- 実際に UI へ出すのは V の ♭9 / #9 / #11 / ♭13 の 4 つと、§3 の 3 つ。`7alt` / `7(♭9,♭13)` / `7(#9,♭13)` / `13(♭9)` はカタログに定義だけあり、未露出
- Pro ゲートは既存ポリシーに従う（実装時に `tags: ['pro','jazz']`）
- MIDI / 表示 / intervals の三者一致をテスト必須とする
