# Accent

---

## 1. 定義

拍・声部・役割ごとの強調。Velocity パターンの骨格であり、Humanize（微小揺らぎ）とは分離する。

---

## 2. Velocity アクセント基準

### 2.1 GT-001 校正後（正・優先）

出典: `GroundTruthMidi.md` GT-001（125BPM_allday_Piano）

| 役割 | MIDI vel（p25–p75） | median | 正規化 gain 目安 |
|---|---|---|---|
| Downbeat | 68–83 | **75** | 0.53–0.65 |
| Upbeat | 63–77 | **71** | 0.50–0.61 |
| 16 分裏（e / a） | 63–77 | **70.5** | 0.50–0.61 |
| Soft / ghost 寄り | 37–55 | — | 0.29–0.43 |
| 全体 | 64–79 | **73** | ピークは 100 までに抑制 |

特徴: ダウンビートと裏の差が **小さい**（打ち込みの均一感）。強拍を極端に叩かない。

### 2.2 旧仮値（参考・非推奨）

| 役割 | 旧 MIDI 目安 | 備考 |
|---|---|---|
| Downbeat | 95–110 | GT-001 より熱すぎる |
| Upbeat | 70–90 | 上端のみ近い |
| 16 分裏 | 60–80 | 帯は近いが運用は §2.1 |

---

## 3. プロファイル表現

```ts
velocityAccent: number[]  // 長さ 4 = 拍ごと乗数。空 = パターン内 vel のみ
ghostDensity: number      // 0–1
```

GT-001 向け初期提案:

- `velocityAccent` は緩やか（例: `[1.05, 0.97, 1.02, 0.97]`）か空  
- pattern 内 vel を **0.55–0.75** 帯に寄せる  
- ghost は **0.30–0.43**  

---

## 4. 変更ルール

- Accent を変えるときは本ファイルと該当 pattern 文書を同時更新  
- 新しい正解 MIDI で上書きしたら `GroundTruthMidi.md` を先に更新  
- groove-reviewer が「全部同じ強さ」「突然 100 超えだらけ」等をチェックする
